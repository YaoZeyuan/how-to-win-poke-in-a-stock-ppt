# 零: 投资是道必考题

> 我们讨论投资的目标不是劝人下场，而是了解什么时候不应该下场

在我看来：**投资是我们每个人都绕不开的必考题**，提前了解是有必要的。

当然，这里的投资，并不只是炒股。只要是我们对有限的资源进行调配并期望有所回报，都可以认为是投资。包括不限于

- 我们发了工资是存款还是消费 -> 资金有限
- 离提测还剩一小时是先修bug还是先写文档 -> 时间有限
- 两个offer，是钱多事多还是钱少事少 -> 方案有限
- 手里两个P0事项，做一个就必然要放弃另一个，是先做A还是先做B -> 精力有限

这些事项的本质，就是在信息并不完整的情况下，把今天掌握的资源配置到未来，并承担判断错误的后果。甚至于：**不作选择，本身也是一种选择**

答案是20轮，按交易十只股票，一天一轮的话，完成从千万富翁到万元户大概只需要一个月

- 20轮下来财富剩余 1000 * 0.778^20 = 6.6万元

# 一: 何以为「赢」

我们直接拍一个「赢」的北极星指标：「以保障家庭幸福度为前提，在5~10年尺度上，实现可置信的家庭净资产增长」

也就是说，能够可置信的，在长期尺度，实现家庭净资产的增长，即被视为赢。

基于这个指标，我们就可以把投资对我们的重要度进行量化

$$
资产管理体系重要度 α ＝ \frac{可投资额}{稳定年收入}
$$

| [资产管理体系重要度](https://mp.weixin.qq.com/s/p6ZpZkjPbJiu7TUibSE0Gw) | 理财收益增加10%,年收入增加- | 阶段事项                   |
| :---------------------------------------------------------------------- | :-------------------------- | :------------------------- |
| 0 < α < 1                                                               | 10%                         | 提升自身实力/薪资          |
| 1 <= α < 4                                                              | 10%~40%                     | 继续深耕职场，验证理财思路 |
| 4 <= α < 10                                                             | 40%~100%                    | 合理配置资产               |
| 10<= α < 60                                                             | 100%~600%                   | 评估风险，规避损失         |
| 60 <= α                                                                 | -                           | -                          |

我们可以根据这个α值，直观衡量当前工作和投资对我们的重要程度。举个例子，已知巴菲特享誉全球是因为他做到了年化20%的投资回报率，而张三如果想在工作的第一年让家庭资产增加速度达到巴菲特水平，他需要在12个月正常薪资外，额外获取多少个月的年终奖才能达到巴菲特水平？

答案是2到3个月。 2/12=16.67%, 3/12=25%，即使张三发的工资一分不花，在工作的第一年，绩效2个月相当于追平巴菲特，3个月就能战胜索罗斯。

一般来说，我们可以用十年期国债基准利率的倍数作为量化指标。

| 倍数 | 风险级别     | 对应人群                                                                                                                    |

那作为衡量风险的基准，谁知道目前「十年期国债基准利率」大概是多少？

# 三：可行策略：扑克牌新手如何参加全国斗地主锦标赛

那么问题来了，扑克牌新手如何参加全国斗地主锦标赛呢？

理论上的最优解是听从巴菲特的劝告，不玩，不玩就绝不会亏。

但我们一开始论证过，我们早晚会投入这滚滚红尘，所以这个至少在这次分享中不是最好的策略。

那次优解是什么，有没有一个方案，能够让你在进入A股后，还能可置信的实现家庭净资产增长？难度类比于提供一个方案，可以让我六岁的侄子100%战胜两位全国斗地主冠军。

方案还是有的----只有抓到满手王炸后，再入场。

举个例子：

- 假如我们所选的是不死品种：比如上证指数，中概互联，纳斯达克
- 假如我们相信经济有周期，这些指数的价格会围绕价值上下波动
- 那么我们在它低价时买入，高价时卖出。不跌到足够低绝对不出手，不涨到足够高也绝不卖出。是不是能够可置信的保证：一定不会输？

# 四：资产配置：为什么即使必胜，也不应该全部投入

因为正确的买入只是获取收益的第一步，甚至不是最重要的一步。

> `策略正确 ➡️ 仓位正确 ➡️ 资金链不断 ➡️ 坚持到兑现 ➡️ 最终赚钱`

以[碧桂园为例](https://mp.weixin.qq.com/s/asD_Vw3jMGzUOD7J6h4_Pg)，他们2021年9亿投资长鑫，2023年ChatGPT出现，24年时AI大势已成共识，长鑫爆赚和a股上市的路径都已经确定。但由于房地产崩盘，碧桂园被迫在2024年以20亿的低价将股份卖给了安徽国资----按市价大概少赚400多亿。

另一个例子是李嘉诚的儿子99年以220万美元投资腾讯，占腾讯20%的股份，到了2001年，这些股份涨到了1260万美元，盈利600%。在当时不管以任何视角这都是天才投资家的水平，所以李泽楷也大大方方的把股份卖给了南非报业。唯一的缺点是，按腾讯历史最高市值看，这些股份可以达到1800亿美元。

所以，策略正确只是第一步，甚至坚持到兑现也不见得能赚到不后悔的收益。而如果资产配置不当导致资金链断裂，甚至没有兑现的机会。

> 另一个问题是做到「不卖出」远比想象中难得多
> ![极端场景下的情绪风险](![image](https://tvax4.sinaimg.cn/large/006GAeg6gy1ifl3ylt6goj32ye1j01kx.jpg))

从某种意义上说： **收益率可以决定家庭财富上限，而具体仓位则决定了家庭财富下限**。一个典型案例就是：假如我们买房买车，这笔资产，将占我们家庭资产的百分之多少，以及，这合适吗？

所以资产配置本身是重要的，但如何开展资产配置呢？

- ❌ 了解可选投资标的
- ❌ 配置资产占比比例
- ❌ 提前预知资产风险并做出应对
- ✅ [先统计出自己有多少钱](https://youzhiyouxing.cn/x/balance_sheet)

# 五：汇总

简而言之，今天的分享主要是这三个部分

- 对于投资：早晚都做，一定会亏，早亏不如晚亏
- 对于股票：不懂不做，(如果要做)低买高卖，(如果高买)控制比例，(如果没能控制)做好心理预期
  - [曹名长：对于单一投资项，仓位上限控制在5%](https://www.xiaoyuzhoufm.com/episode/617f736ac890259cb983e302)

最后结语：

- 优先保证现金流
- 万全之后再考虑资产增值
- 永远给错误留空间（我们一定会犯错，问题是错了怎么办）
