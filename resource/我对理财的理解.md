# 我对投资/理财的理解：扑克牌新手如何参加全国斗地主锦标赛

# 引子: 为什么要主动尝试投资

相信前不久长鑫上市的消息大家应该听说了，可以说，在我看来，2024年9月开始的这轮牛市，是A股过去十年最好的一年。但缺点是很可能也是未来十年最好的一年：突出体现为我在微信群里看到的这段话

> 你是怎么开始接触股票的？
> ❌ 朋友推荐
> ❌ 从社交媒体获知
> ❌ 从财经新闻得知
> ✅ 仇人陷害

所以问题来了：我们只是想挣点小钱而已，理个财就这么难吗？

难度可能比我们想象中要高不少，而且还不可逃避。

举个例子，假如腾讯宣布公告，委派0经验的校招生负责微信底层数据库架构升级，一旦失败微信直接闪退数据永久丢失。这相当于让一个没有经验的人，去尝试做会造成不可挽回损失的风险操作的事，我们当然知道这不靠谱。但是，换个场景

- 小米su7 30万一辆，我们买之前会考虑多久
- 两个新人结婚，假如每个人都有50万存款，那这是百万资产个人独资的企业合并，我们会考虑多久
- 北京改善型房产普遍500万一套起步，对于这种0.5千万的资产事项， 在决定购买前，我们会考虑多久

这些都可以看作投资，而且一旦决策失败，几乎必然会对家庭资产产生不可挽回的损失。但买车买房结婚生子，这总是很合理的需求，而我们显然不想承担一旦决策失败产生的巨大损失，所以，了解点投资是有必要的

> 兵者 国之大事 死生之地 存亡之道 不可不察也
> by 孙子

另一方面，即使我们不买车买房，但仅从概率视角，未来60年，我们总有一天会按耐不住投身股市准备理财。

![自己的失败固然令人遗憾，但兄弟的成功则更令人揪心](https://tvax2.sinaimg.cn/large/006GAeg6ly1ifk72vou2rj30u00gvwgb.jpg)

而贸然开启投资，就相当于物理意义上的稚子抱金于闹市，对我们对家庭都是非常危险的事情。举个例子，假如我们有千万家财，投资技术也非常高超，炒股总是四赢六亏，十次一轮，每次盈亏比例都是10%。那么经过几轮可以把我们从千万富翁炒成万元户？

答案是20轮，一天一轮的话，大概只需要一个月

- 每轮下来财富剩余1.1^4 * 0.9^6 = 77.8% 
- 20轮下来财富剩余 1000 * 0.778^20 = 6.6万元

> 你不理财，财不离你

![邹市明的理财之道](https://tvax4.sinaimg.cn/large/006GAeg6ly1ifk76dal1rj30bf0j6jvb.jpg)

所以我考虑的点是，如果早晚有一天，我们注定要踏入这滚滚红尘，按比例亏钱。那么提前应对，完成认知，降低亏损，总是好一点的方案。

所以，开启投资前的第一件事：用什么衡量我们是否在「赢」

# 何以为「赢」

这里不多讨论，我们直接拍一个「赢」的北极星指标：「以保障家庭幸福度为前提，在5~10年尺度上，实现可置信的家庭净资产增长」。能够可置信的，在长期尺度，实现家庭净资产的增长，即被视为赢。
